## Triage by cause

Nothing crashed or hung, so no mechanical fix was made. Every finding below needs the game's semantics (primitives, autonomy, routing, save format); they are in TODO.md.

1. **Sims stuck in "Atender"** (11 lots, 29 to 69 game hours each): the Main sits in "Answer - Call Not for Answering Sim". Repro: `build/s2pkg autonomy N001/Lots/N001_Lot11.package --ticks 40000 --sim Alexander` (enters at tick 30683 and never leaves).
2. **Save round trip differs on "person data 109"** (14 lots, 1 to 3 Sims each; nothing else differs): the running interaction's uid written by `syncQueueData` changes after load -> save -> load. Repro: `build/s2pkg lot-save N001/Lots/N001_Lot11.package /tmp/o.package --ticks 300 --check`.
3. **Mains that die** (5): instruction budget exhausted (N002_Lot10 Jill, N002_Lot4 Puddle; Jill also shows as stuck in "Praticar"), "Trying to route while out of world" (N002_Lot3 Circe, stuck in "Trabalhando"), "No stack object present when required (Run Tree by Name)" in tree 0x200A of object 777 (N001_Lot18 Dina) and "stack object 136 does not exist" (N003_Lot52 Tybalt). Repro: `build/s2pkg autonomy <lot> --ticks 129600 --sim <name>`.
4. **Sims that starve** (28 deaths, 20 more with motives at -100): in 3 days with no one buying groceries and no bills the Sims run out of food; not necessarily a bug, but the pinned hunger/bladder/hygiene on living Sims (N003_Lot192, N003_Lot46, N003_Lot52 have the most) shows autonomy not finding a way to satisfy them. Repro: `build/s2pkg autonomy N003/Lots/N003_Lot192.package --ticks 129600 --every 1800`.
5. **Long but plausible interactions** (6.1 to 7.1 hours: "Dormir", "Na Escola", "Pintar", "Cochilar"): probably legitimate; "Chorar Baixinho" / "Chorar por Filho Perdido" / "Desespero de Higiene" running for 19 to 60 hours are not.
6. **N002_Lot32.package is not a lot** ("no elevation array (3ARY 0x01): not a lot package?"): the tools fail cleanly with exit 1. Repro: `build/s2pkg autonomy N002/Lots/N002_Lot32.package`.

Not counted as findings: Sims that left the lot (their last interaction is "Leave", and the object id is reused), and "Falecer" (listed as deaths).

## Notes on the script

- Crashes are detected by a signal exit status and re-run once under `lldb -b -o run -o bt` (SOAK_NO_LLDB=1 turns that off); hangs by a watchdog `kill -9` after `SOAK_HANG` seconds; stuck Sims from the "running"/"done with" lines of `s2pkg autonomy` (limit 10800 ticks = 6 game hours); pinned motives from one motive table per game hour (`--every 1800`).
- Scratch saves and screenshots are deleted per lot; only the per-lot findings stay in `OUT/results/*.txt`.
- The app step ran the app built in the main checkout (the Metal compiler is not available here to build the app in the worktree).
